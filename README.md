# expense_tracker
العنوان expense tracker 
الطالب عبدالرحمن طارق الشريف 232849
الطالب اسلام سامي التركي 232842
المجموعة الرابعة

وصف التطبيق :
تطبيق موبايل بسيط تم تطويره يهدف إلى مساعدة المستخدم على تسجيل وتتبع مصروفاته اليومية بطريقة سهلة وبدون الحاجة إلى اتصال بالإنترنت.

مميزات التطبيق :
عرض إجمالي المصروفات الشهرية
تصنيف المصروفات حسب الفئة والتاريخ
عرض قائمة بالمصروفات 
تخزين البيانات محليًا 
يستخدم sqflite لتخزين البيانات محليا في الجهاز 
كما يستخدم ChangeNotifier ك provider  لتوصيل البيانات بين الشاشات 

 التطبيق به اربعة واجهات :

add_expense_screen
expense_detail_screen
expenses_list_screen
home_screen

لعرض التطبيق لديك ضع ملف lib بدل في مشروع flutter 
ضع ملف pubspec.yaml في مكانه في نفس المشروع
قم بتنفيذ امر pub get من terminal 
قم ب run للتطيق
